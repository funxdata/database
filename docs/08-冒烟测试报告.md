## 分析

### 功能链路

- **建表**：`db_create` 正常创建普通表，表名经过白名单校验并加引号。
- **写入**：`db_insert` 支持单条 SQL 多 VALUES，本次 3 行一次写入；Unicode 文本可正常写入。
- **查询**：`db_query` 正确返回列名、整数与文本类型；查询结果与写入内容一致。
- **更新**：`db_update` 后立即回查，字段值符合预期，说明 WAL 下读写一致。
- **删除**：`db_delete` 后剩余行数正确，删除条件生效。

### 校验与错误码

- 缺少 `table` 返回 `400102`。
- 非法逻辑库名 `../escape` 在打开阶段被拒绝，返回 `500100`。
- 非法表名 `bad name` 被拒绝，返回 `500101`。
- 错误码与 `docs/03-FFI接口规范.md` 一致。

### 性能观察

- 首次 `db_create` 约 4.69 ms，包含动态库加载、首次连接打开与 PRAGMA 初始化。
- 后续同类操作均在 0.06–0.24 ms 量级，连接按线程缓存后复用。
- 该数据为单次冒烟运行的墙钟时间，**不是基准测试**；正式性能评估应使用 `ts/sqlite_stress.ts`。

### 覆盖边界

本次冒烟覆盖 5 个导出功能与关键输入校验。以下场景不在本冒烟范围内：

- 超过 1 MiB 的响应与分页（按业务约束不会触发）。
- 并发写压力（已在 `tests/db_test.rs::concurrent_writes_are_accepted` 覆盖）。
- schema 版本迁移（当前库未提供迁移机制）。
- 非 UTF-8 TEXT 的替换字符行为。

## 结论

5 个导出功能均通过冒烟测试，读写一致性、Unicode 与错误码校验正常；当前版本可进入后续集成验证。
