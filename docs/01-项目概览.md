# 01 · 项目概览

## 定位

`database`（`dytes.json` 描述为 *system for database management*）是一个**嵌入式/本地**的小型数据库运行时：

- 使用 Rust 编写，编译为动态库（`cdylib`），通过 C ABI 被其它库文件或宿主进程加载。
- 数据持久化使用 SQLite，编译时启用 `bundled`，不依赖系统 SQLite。
- 不包含向量检索能力（原 sqlite-vec 集成已移除）。
- **不提供 HTTP 服务**：经 `cyctron` 等 HTTP 网关的请求不能调用本库；调用方必须是能直接加载动态库的库文件/进程。

因此它更像一个**宿主进程内的数据库插件**，而不是独立的数据库服务器。

## 能力清单

| 能力 | 导出函数 | 说明 |
| --- | --- | --- |
| 建表 | `db_create` | 按调用方给出的表名与 schema 创建普通表 |
| 写入 | `db_insert` | 执行任意单条 INSERT SQL |
| 更新 | `db_update` | 执行任意单条 UPDATE SQL |
| 删除 | `db_delete` | 执行任意单条 DELETE SQL |
| 查询 | `db_query` | 执行 SELECT，结果序列化为 JSON 数组 |

**不支持 / 未提供**：HTTP 接口、向量检索、参数化查询、事务 API、索引管理、迁移、分页、连接池、加密、鉴权。

## 技术栈

| 组件 | 版本/形式 | 用途 |
| --- | --- | --- |
| Rust | edition 2021 | 实现语言 |
| `rusqlite` | `0.37`，`bundled` | SQLite 绑定，静态编译 SQLite |
| `safer-ffi` | `0.1.13` | 生成 C ABI 导出 |
| `serde` / `serde_json` | `1.0` | 请求解析与响应序列化 |

## 关键约束

1. **仅库文件调用**：不提供 HTTP 接口，`cyctron` 的 HTTP 请求无法调用本库。
2. **数据目录固定**：数据库文件始终位于进程 CWD 下的 `./database/`，无法配置。
3. **连接按线程缓存**：同一线程同一库复用连接；不同线程各自持有连接，WAL + 5 秒 `busy_timeout`。
4. **JSON 缓冲区固定 1 MiB**：响应超过上限会失败且无截断数据返回。
5. **SQL 由调用方拼装**：接口接收完整 SQL 字符串，不提供占位符绑定。
6. **线程模型由宿主决定**：库内部只使用单个 `rusqlite::Connection`/调用，未做连接池或全局锁设计。
